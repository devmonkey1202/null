## 6. 작업 시 유의사항

1. **기능/로직 변경 금지**: 문자열·주석·aria-label 등 **텍스트만** 교체한다.
2. **원본과 동일하게**: `\uXXXX`는 유니코드 코드포인트이므로, 치환 시 **의미가 동일한 한 글자**로 1:1 매핑하면 원본과 동일하다.
3. **모지바케(����)**: 원문이 없으므로, 위 표와 같은 **맥락(주변 UI·변수명)**으로 복원한다.
4. **한 번에 하나씩**: 같은 깨진 문자열이 여러 곳에 있으면, **충분한 주변 코드를 포함한 old_string**으로 구간을 지정해 치환해 오차를 줄인다.
