# NULL 검증 체크리스트

## 목적
이 문서는 구현된 기능이 실제 서비스 운영 수준을 충족하는지 검증하기 위한 기준표입니다.
체크리스트는 실행 증거와 반드시 1:1로 연결되어야 합니다.

## 1. 보안 기준
- [ ] 샌드박스가 메인 DOM/스토리지/쿠키에 직접 접근하지 못함
- [ ] 플러그인 권한 없는 액션은 실행이 차단됨
- [ ] 메시지 브릿지가 허용된 액션만 처리함
- [ ] 서버리스 노드 입력/출력/타임아웃 제한이 강제됨
- [ ] DEV/PROD 데이터 경계가 유지됨

## 2. 성능 기준
- [ ] 대규모 문서(수천 노드) 렌더가 치명적 지연 없이 수행됨
- [ ] 위젯/플러그인 오류가 전체 렌더를 중단시키지 않음
- [ ] 렌더 루프에서 불순 함수 사용이 제거됨
- [ ] 데이터 바인딩/쿼리 호출이 제한 정책을 준수함

## 3. 기능 통합 기준
- [ ] 위젯 인젝터 ↔ 샌드박스 ↔ 브릿지 통합 동작 확인
- [ ] 플러그인 설치/권한/버전 고정 경로 정상 동작 확인
- [ ] DEV/PROD 분리 및 배포 복제 동작 확인
- [ ] 전역 상태(setGlobalState/토큰/바인딩) 흐름 확인

## 4. 회귀/안정성 기준
- [ ] Lint/Build/Test 결과를 증거 로그에 남김
- [ ] 실패 항목은 원인/위치/재현 명령이 기록됨
- [ ] 수정 후 재검증 기록이 누적됨

## 5. 증거 수집 규칙
- 모든 실행 기록은 `docs/NULL_검증_증거_로그.md`에 남긴다.
- 각 체크 항목은 증거 로그의 실행 ID와 연결된다.
- 실패는 숨기지 않고 그대로 기록한다.
